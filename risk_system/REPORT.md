# ロボット搭載カメラによるリスク検知と安全制御：開発レポート

**ROS 2 Humble + Ignition Gazebo 6（Fortress）／ 2026-10-18 初版、2026-10-31 最終スラローム実験に合わせて更新**

本レポートの結果は、特に断りがなければ最終スラローム実験（ラン `slalom_final5`、ワールド `robot_risk_office_slalom.sdf`）のものです。提出動画は `ros2 camera diag.mp4`（1分04秒）で、このランの録画です。

---

## 1. コンセプト

**「ロボットが自分のカメラで見たものだけを根拠に、危険度を数値で判断し、速度を決める」** システムです。

- **見た目だけのデモにしない。** 事前に用意した検知結果や、時間で決めた動きは使いません。Gazeboが描画したロボット搭載カメラの画像が、ROS 2を通って検知ノードに届きます。検知ノードがリスクを計算し、制御ノードが速度指令を出します。このループが実際に閉じていることを重視しました。
- **危険を「ある／なし」ではなく0〜100のスコアで表す。** 遠い・近い・進路上・進路外・人かどうかを1つの数値にまとめます。減速・停止・回避・待機を連続的に切り替えます。
- **わからない時は止まる。** カメラが止まった、画像がおかしい、検知結果が古い、コントローラが落ちた。どの場合も「安全側＝停止」に倒れるように設計しました。
- **測っていないものを測ったふりをしない。** 単眼カメラの距離は推定値です。人の判定は形状のルールです。ここまでできて、ここからはできない、という境界をはっきり示します。

### 3.3 最終実験のシナリオ

ロボットは (−5.0, 0) から +x 方向へ向かい、相対 (11.0, −0.4) m の目標を目指します。

| 対象 | 位置 (x, y) [m] | 実際の動き |
|---|---|---|
| obstacle_1（段ボール箱） | (−1.4, +0.4) | 右側を通過 |
| obstacle_2（ケース） | (1.4, −1.0) | 左側を通過 |
| 人 | x = 3.2、y を −2.2 → +1.7（0.4 m/s） | 停止して通過を待ち、自動で再開 |
| obstacle_3（収納ボックス） | (5.0, +0.55) | 右側を通過 |

人の動きはシナリオ上の動きで、`set_pose` で位置を更新します（足を動かす歩行ではありません）。ロボットが5.0 m進むと歩き始めます。

## 4. リスク計算のしくみ（特徴）

### 4.1 床の境界から距離を推定する（色に依存しない）

1. **床の外観を学習する：** 起動時に、画像最下部の中央を床として種にします。その後は、床と判定した画素から行ごとに色を更新します。
2. **画像の列ごとに下から上へ走査する：** 次のどちらかに当たった最初の行を、床の境界とします。
   - 隣の行との色の差が大きい（エッジ）
   - 学習した床の色から外れる
3. **境界の行を推定距離に換算する：** 平坦な床の上に物体が立っていると仮定し、ピンホールモデルで計算します。

   d = h / tan(θ<sub>pitch</sub> + atan((v − c<sub>y</sub>) / f))
   （h = 0.67 m、θ<sub>pitch</sub> = 0.10 rad、f = 550 px）

4. **物体にまとめる：** 距離の近い列をまとめて物体とし、左右端の横位置・幅・高さを求めます。高さは、物体より奥にある左右の背景と比べて求めます。

物体の色を一切使わないので、赤い箱でも段ボールでも黒いケースでも、同じ方法で検出できます。

### 4.2 人の判定

次の条件をすべて満たす物体を「人」とします（形状のルール）。

- 高さ1.15〜2.1 m
- 床との接地部が細い（脚の部分）
- 縦長（高さ／幅 ≥ 1.9）
- 独立して立っている（左右とも画像の内側にあり、少なくとも片側で奥行きが途切れている）

YOLO11nも試しました。しかし1枚に約2秒かかり、箱形の人モデルも検出できなかったため、採用しませんでした。

### 4.3 リスクスコア（0〜100）

```
risk = 100 × 接近度 × (0.3 + 0.7 × 進路係数) × (0.7 + 0.3 × 信頼度)
```

| 要素 | 定義 |
|---|---|
| 接近度 | 障害物：3.5 m（0）〜1.4 m（1）。人：4.5 m〜1.9 m（人はより遠くから評価する） |
| 進路係数 | ロボットの通路（±0.40 m）にかかれば1。外れるほど0.6 mかけて0まで下がる |
| 信頼度 | 境界のコントラストと物体の幅から算出（0〜1） |

### 4.4 状態とロボットの動作

| 状態 | 条件 | 動作 |
|---|---|---|
| CLEAR | 検出なし | 0.30 m/sで前進 |
| OBSTACLE_FAR | リスク < 30 | 0.30 m/sで前進 |
| APPROACHING | 30以上70未満など | リスクに比例して減速（下限0.15 m/s） |
| PERSON | 通路内で4.5 m未満、または3 m未満に人 | 0.12 m/sで徐行（1.0 m以上横にいる人では徐行しない） |
| STOP | リスク ≥ 70（60未満になるまで解除しない）、かつ進路上または1.25 m以内 | 停止。障害物なら迂回、人のリスクが60以上なら待機 |
| INVALID | 画像なし・途絶・停止・一様な画像・サイズ不一致 | 即停止 |

速度は最終実験の設定値です（`run_slalom.sh` の既定値）。迂回中は最大0.25 m/s、経路の確認中は0.22 m/sです。

## 5. 工夫した点

1. **障害物の端を実測して迂回する。** 停止した位置で、カメラが測った障害物の左右端から0.65 m離れた2つの経由点を、オドメトリ座標で計画します。通過中は、経由点までの線分が検出物体から0.45 m以上離れているかを幾何的に確かめてから進みます。迂回した障害物の位置は記憶し、視野の外に出ても、そちらへ曲がらないようにします。
2. **人の周りは迂回しない。** 人が進路にいる時は、停止して待機します。近くに物体がなくなって1秒経ってから再開します（上限12秒）。
3. **安全を何重にも確保した。**
   - 検知ノードは、画像の途絶や異常を INVALID として出す。
   - コントローラは、リスク状態やオドメトリが途絶えたら停止する。
   - watchdogは、コントローラが落ちても止める。DiffDriveは最後の速度指令を保持し続けるため、これがないとロボットが走り続けます。
4. **動画の中身はすべて実データ。**
   - 録画はシミュレーション時間に同期しているので、再生速度＝実際の動きです。
   - キャプションは実際の状態から自動で決まります。提出動画に文字カードはありません。
   - 人の移動だけはシナリオ上のイベントで、画面にそう表示しています。
5. **再現できる運用にした。**
   - 起動スクリプトは重複起動を防ぎ、PIDを管理します。
   - SDFを変更する前は、毎回バックアップを取りました。
   - 全部を停止してから起動し直しても、同じ結果になることを確認しました。

## 6. 苦労した点（見つけた問題と対処）

| 問題 | 原因 | 対処 |
|---|---|---|
| カメラが灰色一色しか映さない | ロボットが後ろに38°傾き、空だけを見ていた。二輪が同じ軸に並ぶ配置で、支えがなかった | キャスターを前後に追加 |
| オドメトリは進むのにロボットが動かない | 車輪の関節軸が、90°回転した車輪の座標系で解釈され、車輪がコマのように縦軸まわりに回っていた | 軸を `0 1 0` から `0 0 -1` に修正。真値とオドメトリが一致 |
| 走行中に車体が前後に揺れる（±1.92°） | キャスターと床のすき間が5 mm | 2 mmにして±0.77°に抑えた。2 m先の距離誤差は±0.1 m程度 |
| 処理が遅い（RTF 0.35、カメラ約3 Hz） | 古いYOLO検出器2つと、テスト用ワールド2つがCPUを占有していた | 承認を得て停止し、RTF 0.88に回復 |
| 迂回中に止まったまま進めない | 正面方向で判定したSTOPが、迂回中の経路まで止めていた。経由点の消し込みも遅れていた | 線分クリアランスによる判定、経由点の処理順の修正、STOPのヒステリシス |
| 横にいる人で停止して進めない | 進路外でもリスク70を超えるとSTOPになっていた | STOPは「進路上または至近距離」に限定 |
| シーンを戻した後、目標がずれる | set_poseで位置を戻しても、オドメトリはリセットされない | 目標を「起動時の姿勢からの相対位置」で指定 |
| カメラのPublisherが2つになる | 停止処理が `ros2 run` の子プロセスを残していた | プロセスグループごと停止するよう修正 |
| オフィスで距離が0.2 m短く出る | 斜めの光で、影が手前に伸びていた | 照明をほぼ真上からに変更 |
| オフィスで人を障害物と誤判定する | 背景が空でなく壁になり、高さが測れなかった | 奥側の左右の背景と比べる方式に変更 |
| 扉を人と誤判定する | 縦長の壁の一部が条件に合っていた | 「独立して立っている」条件を追加。厳しすぎた分は緩めて、両方のワールドで再テスト |
| ケースと奥の植物を人と誤判定し、待ち続ける（try2） | 重なって縦長に見え、遠くの誤判定でも待機していた | 待機は、その人自身のリスクが60以上の時だけにした。誤判定そのものは残っている |
| 迂回の基準がずれて止まる（try3） | 最も近い物体を基準に計画していた | STOPの原因（最大リスク）の物体を基準にし、10秒ふさがれたら反対側を試す |
| 障害物に事実上接触（try4、クリアランス −0.022 m） | 迂回後、視野から外れた障害物へ向かって曲がった | 障害物の位置の記憶を追加。配置も調整 |
| 人が進路の近くにいるうちに再開（final4） | 近距離で人のラベルが obstacle に変わった | 待機中はラベルによらず近くの物体を確認する |

## 7. 結果

### 7.1 最終スラローム実験（`slalom_final5`）

根拠：`logs/slalom_final5.csv`、`logs/slalom_runs.txt`。

| 項目 | 値 |
|---|---|
| 目標到達 | はい。終了位置 (5.74, −0.56) m（真値） |
| 走行時間 / 経路長 | 59.2 s / 11.03 m |
| 最大の速度指令 | 0.30 m/s（走行中の平均0.202 m/s） |
| 最小クリアランス | 0.268 m（obstacle_2、ロボット外接円基準） |
| 最大ピッチ | 0.78° |
| 流れ | 右へ迂回 → 左へ迂回 → 人を待機（2.9 s）→ 再開 → 右へ迂回 → 到着 |
| STOPへの遷移 / INVALID | 5回 / 0回 |

同じ配置で設定が少し異なる try5、try6、final3、final4 も目標に到達しました（最小距離0.249〜0.310 m）。全ランの記録は `SLALOM_RESULTS.md` にあります。

### 7.2 速度を上げた状態の測定（0.30 m/s）

根拠：`logs/slalom_speed_metrics.txt`。

| 項目 | 結果 |
|---|---|
| 停止距離 | 0.010〜0.011 m（3回）。ゼロ指令でほぼ即座に止まるシミュレーションの値で、実機の値ではない |
| 検知の遅れ | 132〜330 ms（シミュレーション時間、6回） |
| ピッチ | 最大0.98°（駆動時） |

### 7.3 検知の精度（Gazeboの真値と比較）

根拠：`logs/office_detection_sweep.csv`、`logs/plainworld_detection_sweep_newdetector.csv`。スラロームのワールドでは測っていません。

| 対象 | 真の距離 | 結果 |

| リスクの変化（オフィス） | 障害物までの距離 4.0 → 1.3 m | 0 → 2 → 34 → 49 → 72（停止） → 89 → 96 → 100 |

## 8. 制約と今後の課題

- **確認したのは1つの配置だけです。** 回避は、このレイアウトでしか確かめていません。最終設定そのものでの実行は1回で、比較実験もしていません。スラロームの調整中には、途中停止が2回、事実上の接触が1回ありました。
- **人の判定は形状のルールです。** 箱形の人モデルでしか検証していません。近距離で人が obstacle に切り替わる場面や、ケースと奥の植物を人と誤判定する場面も残っています。実際の人の形状やアクター（歩く人）には、学習済みの検出器が必要です。
- **距離は単眼カメラによる推定です。** 平坦な床を仮定しています。カメラから約1.2 m以内は死角です。測距センサー（LiDARなど）を加えれば、この2点を補えます。
- **cmd_velのブリッジ自体が止まると防げません。** DiffDriveは最後の指令を保持し続けます。Gazebo側に速度指令のタイムアウトを設ける必要があります。
- **オフィス環境は描画が重いです**（RTF約0.4〜0.5）。タイムアウトは実時間で判定するので、RTFが1に近い環境では停止までの距離が伸びます（見積もりで最大約0.45 m＋制動、未測定）。家具は単純な形状の組み合わせで、床は単色です。床に模様がある場合は試していません。
- **人の移動はシナリオ上の動きです**（set_pose）。足を動かすアクターは未実装です。
- **カメラの視野は前方60°です。** 視野の外の障害物は記憶で避けているだけで、記憶していない物体は避けられません。
